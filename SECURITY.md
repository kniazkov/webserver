# Security Policy

## Supported Versions

| Version | Supported |
| --- | --- |
| 2.0.x | Yes |
| 1.x | No |

Only the current 2.0 release line receives security fixes.

## Reporting a Vulnerability

Do not open a public issue for a suspected vulnerability. Report it privately
through [GitHub Security Advisories](https://github.com/kniazkov/webserver/security/advisories/new).

Include the affected version, a minimal reproduction, the expected impact, and
any suggested mitigation. Please avoid testing against systems or data that you
do not own.

The maintainer will assess the report, coordinate a fix and disclosure when
appropriate, and credit reporters who want to be acknowledged.
